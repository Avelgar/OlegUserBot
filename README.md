# 🤖 Oleg AI Userbot

Персональный Telegram юзербот с интеграцией искусственного интеллекта **Google Gemini 2.0 Flash**.
Бот умеет поддерживать диалог, запоминать контекст беседы, а также анализировать фотографии и видео (включая альбомы).

Олег в телеграмм: @oleg_userbot
---

## 🌟 Основные возможности

### 🧠 Интеллектуальное общение
* **Gemini 2.0 Flash:** Использует новейшую модель от Google для быстрых и точных ответов.
* **Контекстная память:** Бот запоминает историю диалога (последние 15 сообщений), что позволяет вести связную беседу.
* **Голос бренда:** Отыгрывает роль персонажа "Олег".

### 👁️ Мультимодальность (Зрение)
* **Анализ медиа:** Можно отправлять боту фотографии и видео — он поймет, что на них изображено.
* **Поддержка альбомов:** Умная система буферизации собирает отправленные группой фотографии (альбомы) и отправляет их в AI одним запросом, а не по отдельности.

### ⚙️ Логика работы
* **Личные сообщения:** Отвечает на все сообщения автоматически.
* **Групповые чаты:** Отвечает только при обращении по триггер-слову **"олег"**.
* **Управление историей:** Команда `очистить историю` удаляет контекст переписки из базы данных для текущего чата.

---

## 🛠 Технический стек

* **Язык:** Python 3.10+
* **Telegram API:** Telethon (Userbot)
* **AI Engine:** Google GenAI SDK (`gemini-2.0-flash`)
* **База данных:** MySQL (хранение истории сообщений)
* **Асинхронность:** Полностью асинхронная архитектура (asyncio).

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/Avelgar/OlegUserBot.git](https://github.com/Avelgar/OlegUserBot.git)
cd OlegUserBot
```

### 2. Установка зависимостей
```bash
pip install telethon google-genai mysql-connector-python
```

### 3. Настройка базы данных (MySQL)
Создайте базу данных и укажите параметры подключения в файле userbot.py. Таблица messages создастся автоматически при первом запуске.

### 4. Конфигурация
```python
# Telegram API (получить на my.telegram.org)
API_ID = 12345
API_HASH = 'ваш_api_hash'

# Gemini API (получить в Google AI Studio)
GEMINI_API_KEY = 'ваш_ключ_gemini'

# База данных
DB_CONFIG = {
    'user': 'root', 
    'password': 'password',
    'host': 'localhost',
    'database': 'oleg_bot_db',
    # ...
}
```

### 5. Запуск
```bash
python userbot.py
```

## 📝 Примеры использования

### В личном чате
> **Вы:** [Отправляете фото ингредиентов в холодильнике]
> **Вы:** Что из этого можно приготовить на ужин?
>
> **Олег:** Вижу яйца, помидоры, сыр и зелень. Рекомендую сделать шакшуку или сытный омлет с овощами!

### В групповом чате
> **Вы:** Народ, кто знает, какая завтра погода?
> *(Бот молчит, так как нет триггер-слова)*

> **Вы:** Олег, расскажи шутку про программистов.
> **Олег:** Заходит тестировщик в бар, заказывает кружку пива, 0 кружек пива, 99999 кружек пива, ящерицу...

### Команды управления
> **Вы:** Олег, очистить историю.
> **Олег:** История сообщений этого чата очищена! 🧹
